# License and Third-Party Material Policy

## Project-authored material

- Source code: Apache-2.0.
- Project-authored documentation: CC BY-SA 4.0.
- Project-authored CAD: CC BY-SA 4.0.
- Project-authored component/rules data: CC BY-SA 4.0 initially.

## Third-party material

Manufacturer STEP files, DXF files, drawings, datasheets, logos, photographs, and standards publications may have redistribution restrictions even when publicly downloadable.

Default policy: **store a URL plus metadata, not a copy**, unless the source explicitly grants redistribution rights compatible with this repository.

Every imported asset must record:

- source URL
- source organization
- retrieval date
- stated license/terms, if any
- whether redistribution is permitted
- checksum when a local copy is permitted

## Standards

Do not paste copyrighted standards text or tables into the repository merely because the team owns or can access the standard. Store project interpretations, formulas, rule outputs, section references, and independently authored tables only after confirming that doing so is legally permissible.
