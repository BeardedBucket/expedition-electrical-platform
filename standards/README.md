# Standards Data

This directory holds project-authored, versioned engineering datasets and references used by the rules engine.

Start with conductor and voltage-drop support, but do not commit copyrighted standards text without permission.

Suggested initial datasets:

- copper conductor resistance by gauge and reference temperature
- allowable ampacity tables under the selected installation assumptions
- voltage-drop targets by circuit class
- conductor bundling/temperature derating factors where permitted to be represented
- overcurrent-protection constraints
- AC branch-circuit constraints relevant to mobile installations

Every dataset must document edition/revision, provenance, units, assumptions, and review status.
